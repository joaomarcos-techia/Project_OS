# Documentação técnica do Qoro

Comece pelo [índice](index.md), pelo [estado da revisão](overview/current-state.md)
e pelos [percursos de leitura](overview/reading-paths.md).

A navegação do portal está em [docs.json](docs.json), seguindo a estrutura do
Mintlify. Os arquivos continuam em Markdown no repositório; não é necessário
contratar ou publicar documentação para consultá-los.

- [Arquitetura](architecture/overview.md) e [mapa dos contextos](architecture/context-map.md).
- [Cadastro](onboarding/signup.md), [planos](billing/plans-and-seats.md) e [assinaturas](billing/subscriptions.md).
- [Agenda](domains/scheduling-financial.md), [financeiro](domains/financial-policy.md), [IA](ai/agent.md) e [WhatsApp](whatsapp-connection-flow.md).
- [Desenvolvimento](development/setup.md), [testes](development/testing.md) e [operação](runbooks/index.md).
- [Decisões](adr/index.md), [especificações](specs/index.md), [evidências](quality/index.md) e [catálogo de todos os arquivos](catalog.md).
- [Como manter a documentação](engineering/documentation.md).

Código e configuração versionada descrevem a implementação. Testes comprovam
somente o cenário executado. Relatórios, propostas e handoffs históricos são
preservados e classificados; não definem sozinhos a situação atual de Produção.
